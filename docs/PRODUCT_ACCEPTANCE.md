# Ma trận nghiệm thu Creator Loop V1

**Trạng thái 02/10/2026:** đang triển khai. Bảng này theo dõi việc thực hiện, không thay đổi luật trong [Data Architecture V1.1](Creator_Loop_Data_Architecture_V1_1.md), [CI/CD & Release Contract V1](Creator_Loop_CICD_Release_Contract_V1.md), [Layout Contract V1](Creator_Loop_Layout_Contract_V1.md), [Master Prompt V2](Codex_Master_Prompt_V2.md) hoặc [Gate 0 Decision Record](Creator_Loop_Gate_0_Decision_Record.md). Khi trạng thái Git, CI hoặc bản chạy đổi, cập nhật bằng chứng theo đúng commit/artifact.

## Mốc bắt buộc

1. **Gate 0 — quyết định nền:** đối soát contract, stack, migration và test matrix; xác minh máy Windows 8 GB, nguồn và quyền phân phối component trước release. Máy đích đã xác định là máy hiện tại; engine/model V1 chỉ dùng cục bộ và không phân phối. Đường dẫn, phiên bản, nguồn/license của engine/model thực tế và kiểm tra release còn thiếu.
2. **Gate 1 — bootstrap:** source, layout, migration 0001, launcher, CI PR thật và ZIP Windows đã giải nén/smoke; required checks được bật ở GitHub. Nền source/CI có bằng chứng, cần xác nhận trên đúng commit bàn giao.
3. **Gate 2 — Library/Evidence:** nhập Video/Image/Text, original bất biến, nhiều Source cho một Asset, derived file/run, Evidence version và locator mở đúng tệp/đoạn/vùng/text. Có backend nhập TEXT và MP4/PNG/JPEG original, Evidence TEXT tạo/mở qua UI, service Source N:M đã merge ở PR #11; UI Source đang kiểm trên branch. Video/Image locator, derived/run thật và kiểm codec còn thiếu. Gate 2 chưa đạt.
4. **Gate 3 — Knowledge/Creator:** Claim/version/evidence, review events, Project/reference, Draft/version/assertion, chọn A/B/C và kết hợp A+B. Chủ yếu mới có schema; Gate 3 chưa đạt.
5. **Gate 4 — Publication:** Package snapshot/fingerprint, rights, approval/revoke/publish gate, Post và Observation. Có nền Package transaction, còn thiếu luồng sử dụng; Gate 4 chưa đạt.
6. **Gate 5 — release:** lifecycle worker/component, update/migration/backup/restore, manifest/provenance, test chính artifact và máy Windows 8 GB thật, tài liệu sử dụng, tag/release từ `main`. Gate 5 chưa đạt.

## Quy tắc báo hoàn tất

Chỉ báo **product hoàn tất** khi cả 24 dòng bắt buộc có phần triển khai, kiểm tra luồng sử dụng thực tế, CI required trên đúng commit, bản chạy/build cùng hướng dẫn, và toàn bộ release gate V1 đã được xác minh. Nếu thiếu, ghi **đang triển khai**, **bị chặn** hoặc **chờ nghiệm thu** với bằng chứng và bước tiếp theo. Một PR xanh hoặc một Gate đạt không thay thế điều kiện cuối.
